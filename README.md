Gestión de Módulos npm - Módulo 6
Proyecto para la práctica de administración de paquetes en Node.js y Express.

Librerías Implementadas   
Bcrypt: Para la seguridad de contraseñas.
JWT: Para la autenticación basada en tokens.
Dotenv: Gestión de variables de entorno.

Instalación
Clonar el repositorio.

Ejecutar npm install para reconstruir los módulos.

Configurar el archivo .env.
